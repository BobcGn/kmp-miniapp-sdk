# kmp-miniapp-sdk

A Kotlin Multiplatform SDK for sharing client behaviour and host capabilities across Mini App
platforms while keeping rendering host-native.

一个用于在 Mini App 平台间共享客户端行为与宿主能力、同时保持宿主原生渲染的 Kotlin
Multiplatform SDK。
