# Architecture Decision Records

[中文](README-ch.md)

This directory records significant and stable architecture decisions, including their context and consequences.

Use an ADR when a decision materially constrains architecture or future implementation. Do not use ADRs for ordinary TODOs, short-lived implementation details, or roadmap items.

Accepted ADRs are historical records. If a decision changes, add a new ADR that supersedes the old one instead of rewriting the original decision.
